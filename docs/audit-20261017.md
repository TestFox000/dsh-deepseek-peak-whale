### A7. 安装副本漂移（血泪史重现）

- 工作区 vs `~/.dsh/local-packages` 哈希对比：`package.json / index.js / client.js / client.template.js / README.md` 全一致；**但 `vendor/figure.js`、`vendor/pet-core.js`、`vendor/pet-runtime.js` 三份不一致**（工作区 2026-10-12 版更新更大，local-packages 停在 10-04/10-05 版）。
- 成因：`sync_installed.mjs:24` 明文"vendor/ 是上游文件，不动"——**它的 FILES 清单根本不含 vendor/**。工作区 10-12 改过 vendor（手势层）后，从未把 vendor 同步到 local-packages。
- 风险：local-packages 是 pnpm `file:` 指向的 ★RUNTIME 副本，`client.js` 已内联新版贴图与手势，vendor 源文件却停在旧版——违反 AGPL"对应源码"一致性，且 RELEASING.md:31-42 明确警告"升级上游时 vendor 本地改动必须手工重做"。好在运行时只 import 内联后的 `client.js`/`pet-runtime.js`（index.js 不 import vendor），所以功能未坏，但**这是下一次排查"为什么她不抬手"时的头号烟雾弹**。
- 注意：`sync_installed.mjs` 因此永远报"已一致"（它不查自己不同步的东西）——**检查面与同步面相同的自证陷阱**。
